# Custom Skill Service

I can turn one narrow repeatable workflow into a private agent skill for your own business, repo, or team.

Starter price: 499 RMB for one narrow workflow.

Payment is requested after the workflow scope is confirmed.

## Best Fit

This works best when you already have:

- a repeated workflow you run at least weekly
- a clear input, such as notes, tickets, CSV, code diff, issue list, or SOP
- a clear output, such as a report, checklist, review, brief, plan, or template
- one sanitized example that does not expose private data

Good examples:

- turn support tickets into a weekly product triage brief
- audit a release checklist before publishing
- convert messy meeting notes into a client handoff summary
- review a pull request using a team-specific checklist
- create marketplace listing copy from a product spec

## What You Get

The 499 RMB starter build includes:

- short workflow interview through a GitHub issue or async messages
- installable private skill folder
- custom `SKILL.md`
- references, templates, or scripts when useful
- one revision round
- handoff instructions

## What Is Out Of Scope

The starter build does not include:

- guaranteed revenue, traffic, rankings, or sales
- large integrations with private systems
- handling secrets, credentials, or private customer data
- broad "business assistant" or "do everything" agents
- spam, fake account, scraping, or platform loophole workflows

For larger team workflows, implementation scripts, or private tool integration, request a custom quote.

## How To Request

Open a [Custom Skill Request](https://github.com/wrhy66/agent-skill-productizer/issues/new?template=custom-skill-request.yml) with:

- workflow name
- current process
- desired output
- constraints, tools, and file types
- one sanitized example if available

I will reply with whether the workflow fits the starter scope, what I need next, and the expected delivery shape.
