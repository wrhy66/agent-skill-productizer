# Skill Idea Catalog

Use these as starting points for public examples, lead magnets, or private custom-skill offers.

| Skill idea | Buyer | Input | Output | Paid customization |
| --- | --- | --- | --- | --- |
| `release-readiness-audit` | indie SaaS teams | changelog, PR list, checklist | release risk report | repo-specific release checklist |
| `support-feedback-brief` | product managers | support tickets | weekly product triage brief | company tags, severity rubric, Jira handoff |
| `pr-review-rubric` | engineering teams | pull request diff and description | structured review checklist | team conventions and risk areas |
| `marketplace-listing-pack` | plugin/template sellers | product notes and screenshots | listing copy and launch checklist | niche marketplace rules and examples |
| `client-handoff-summary` | consultants | notes, decisions, open items | client-ready handoff document | branded template and account-specific sections |
| `migration-plan-builder` | developers | old API usage and target API docs | migration plan | repo-specific script and test checklist |
| `compliance-packet-check` | operators | required docs and draft packet | missing-item audit | jurisdiction or platform-specific checklist |
| `research-source-synth` | analysts | source links and notes | sourced brief | preferred source hierarchy and citation style |
| `course-lesson-packager` | educators | raw lesson notes | structured lesson pack | school, cohort, or platform format |
| `bug-report-normalizer` | QA teams | messy bug reports | reproducible issue template | product modules and severity rules |

Pick ideas where the user already loses time, money, trust, or release confidence when the workflow is done poorly.
