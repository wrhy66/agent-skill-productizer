# Launch Plan

## Positioning

Agent Skill Productizer helps builders turn repeated AI workflows into installable agent skills with a GitHub-ready wrapper and a clean paid-upgrade path.

## First-Day Checklist

1. Create a public GitHub repo named `agent-skill-productizer`.
2. Upload the repo contents.
3. Add topics:

```text
ai-agents, codex, skills, agent-skills, workflow-automation, prompt-engineering, github
```

4. Pin the repository if the GitHub account has few existing pinned projects.
5. Post the launch copy below in 1-2 places where this is welcome.
